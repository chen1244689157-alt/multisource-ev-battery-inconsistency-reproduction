# Dataset D attribution

The Dataset D analysis derivatives and representative charging-session summaries are derived from:

Zhang, Jingzhao; Wang, Yanan; Jiang, Benben; He, Haowei; Huang, Shaobo; Wang, Chen; Zhang, Yang; Han, Xuebing; Guo, Dongxu; He, Guannan; Ouyang, Minggao (2023). *Realistic fault detection of Li-ion battery via dynamical deep learning approach*. figshare. https://doi.org/10.6084/m9.figshare.23659323.v1

The source dataset is available under the Creative Commons Attribution 4.0 International licence: https://creativecommons.org/licenses/by/4.0/

The present workflow performs charging-window consolidation, session reconstruction, operating-condition feature extraction, brand-wise vehicle-isolated modelling, threshold calibration, vehicle re-aliasing, model inference and metric calculation. The original processed charging-snippet data remain available from the cited Figshare record.
